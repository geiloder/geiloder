# Automation & Cron — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitHub Actions führt täglich um 06:00 Uhr automatisch die gesamte Pipeline aus: Feed-Import → Scoring → Copy-Generierung → Slide-Rendering → Upload zu Supabase. Du musst nur noch ins Admin-Dashboard, approven und herunterladen.

**Architecture:** GitHub Actions Workflows. Alle Secrets sind GitHub Repository Secrets. Playwright läuft headless auf dem Ubuntu GitHub-Runner. Supabase Storage empfängt die Render-Outputs. Ein zweiter Workflow räumt täglich abgelaufene Deals auf.

**Tech Stack:** GitHub Actions, Ubuntu Runner, Playwright, Node.js 20, tsx

### Task 1: Tägliche Pipeline

**Files:**
- Create: `.github/workflows/daily-pipeline.yml`

- [ ] **Step 1: Workflow erstellen**

`.github/workflows/daily-pipeline.yml`:

```yaml
name: Daily Deal Pipeline

on:
  schedule:
    - cron: '0 5 * * *'  # 05:00 UTC = 06:00 DE (Winter) / 07:00 DE (Sommer)
  workflow_dispatch:       # Manuell triggern möglich

env:
  NODE_VERSION: '20'

jobs:
  pipeline:
    name: Import → Score → Copy → Render
    runs-on: ubuntu-latest
    timeout-minutes: 60

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Install Playwright browsers
        run: npx playwright install chromium --with-deps

      - name: Import Awin feeds
        env:
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          SUPABASE_SERVICE_ROLE_KEY: ${{ secrets.SUPABASE_SERVICE_ROLE_KEY }}
          AWIN_FEED_URL: ${{ secrets.AWIN_FEED_URL }}
          AWIN_DEFAULT_PROVISION: '5'
        run: npm run import:awin
        continue-on-error: true  # Nicht die ganze Pipeline blockieren wenn ein Feed fehlt

      - name: Import ADCELL feeds
        env:
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          SUPABASE_SERVICE_ROLE_KEY: ${{ secrets.SUPABASE_SERVICE_ROLE_KEY }}
          ADCELL_FEED_URL: ${{ secrets.ADCELL_FEED_URL }}
        run: npm run import:adcell
        continue-on-error: true

      - name: Score deals
        env:
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          SUPABASE_SERVICE_ROLE_KEY: ${{ secrets.SUPABASE_SERVICE_ROLE_KEY }}
        run: npm run score

      - name: Generate copy (Gemini)
        env:
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          SUPABASE_SERVICE_ROLE_KEY: ${{ secrets.SUPABASE_SERVICE_ROLE_KEY }}
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
        run: npm run generate:copy

      - name: Render slides (Playwright)
        env:
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          NEXT_PUBLIC_SUPABASE_ANON_KEY: ${{ secrets.NEXT_PUBLIC_SUPABASE_ANON_KEY }}
          SUPABASE_SERVICE_ROLE_KEY: ${{ secrets.SUPABASE_SERVICE_ROLE_KEY }}
        run: npm run render

      - name: Generate videos (FFmpeg)
        env:
          NEXT_PUBLIC_SUPABASE_URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          SUPABASE_SERVICE_ROLE_KEY: ${{ secrets.SUPABASE_SERVICE_ROLE_KEY }}
        run: |
          sudo apt-get update -qq
          sudo apt-get install -y ffmpeg
          npm run generate:video
        continue-on-error: true

      - name: Pipeline summary
        if: always()
        run: |
          echo "Pipeline completed at $(date)"
          echo "Check admin dashboard: https://geiloder.vercel.app/admin"
```

### Task 4: Awin Feed-URL herausfinden

- [ ] **Step 1: In Awin Dashboard**

1. https://ui.awin.com einloggen
2. Account → Publisher Data Feeds
3. Feed für ein genehmigtes Programm auswählen
4. URL kopieren — sieht aus wie:
   ```
   https://productdata.awin.com/datafeed/download/apikey/DEIN_API_KEY/language/de/fid/FEED_ID/columns/aw_product_id,product_name...
   ```
5. Diese URL als `AWIN_FEED_URL` in GitHub Secrets eintragen

- [ ] **Step 2: Für mehrere Feeds**

Wenn du mehrere Awin-Programme hast, kannst du `scripts/import-awin.ts` erweitern um mehrere URLs zu unterstützen. Dafür `AWIN_FEED_URLS` (kommasepariert) statt `AWIN_FEED_URL`:

`scripts/import-awin.ts` Anpassung:

```typescript
// Statt:
const feedUrl = process.env.AWIN_FEED_URL

// So:
const feedUrls = (process.env.AWIN_FEED_URLS ?? process.env.AWIN_FEED_URL ?? '').split(',').filter(Boolean)

for (const feedUrl of feedUrls) {
  await importAwinFeed(feedUrl.trim(), provision)
}
```

Und in GitHub Secrets:
```
AWIN_FEED_URLS=url1,url2,url3
```

### Task 5: Monitoring & Benachrichtigung

**Files:**
- Create: `scripts/notify-admin.ts`

- [ ] **Step 1: E-Mail-Benachrichtigung (optional, über Resend — kostenloser Plan)**

Wenn du eine E-Mail-Benachrichtigung nach der Pipeline willst:

Resend Free Plan: 3.000 E-Mails/Monat kostenlos. Account bei https://resend.com

```bash
npm install resend
```

`scripts/notify-admin.ts`:

```typescript
import 'dotenv/config'
import { Resend } from 'resend'
import { createServiceClient } from '../src/lib/supabase/server'

const resend = new Resend(process.env.RESEND_API_KEY)

async function notifyAdmin() {
  if (!process.env.RESEND_API_KEY || !process.env.ADMIN_EMAIL) {
    console.log('RESEND_API_KEY or ADMIN_EMAIL not set — skipping notification')
    return
  }

  const supabase = createServiceClient()

  const [rendered, newDeals] = await Promise.all([
    supabase.from('deals').select('id', { count: 'exact' }).eq('status', 'rendered'),
    supabase.from('deals').select('id', { count: 'exact' }).eq('status', 'approved').is('copy_data', null),
  ])

  await resend.emails.send({
    from: 'pipeline@geiloder.vercel.app',
    to: process.env.ADMIN_EMAIL,
    subject: `✅ Pipeline fertig — ${rendered.count} Deals bereit zum Posten`,
    html: `
      <h2>Tägliche Pipeline abgeschlossen</h2>
      <p><strong>${rendered.count} Deals</strong> sind gerendert und bereit zum Posten.</p>
      <p><a href="https://geiloder.vercel.app/admin/deals?status=rendered">Zum Admin Dashboard →</a></p>
    `,
  })

  console.log('Admin notification sent')
}

notifyAdmin().catch(console.error)
```

### Task 6: Posting-Workflow (manuell)

Nach der automatischen Pipeline ist dein täglicher Workflow:

- [ ] **Morgens (ca. 07:00 Uhr)**

1. https://geiloder.vercel.app/admin/deals?status=rendered öffnen
2. Deals durchschauen (Copy Preview aufklappen)
3. Schlechte Deals rejekten
4. PNGs aus Supabase Storage herunterladen (Storage → assets → deals → [deal_id])
5. Auf Instagram/TikTok posten (oder in Buffer schedulen)

**Caption aus Copy-Daten verwenden:**
- Die `caption` aus `copy_data` direkt als Instagram-Caption verwenden
- `hashtags` anhängen
- In Stories: Link-Sticker auf `/go/[deal_id]?source=instagram` setzen

**UTM-Links für jede Plattform:**
```
Instagram Feed: /go/[id]?source=instagram&utm_campaign=carousel
Instagram Story: /go/[id]?source=instagram_story&utm_campaign=story
TikTok: /go/[id]?source=tiktok&utm_campaign=video
Pinterest: /go/[id]?source=pinterest&utm_campaign=pin
```
